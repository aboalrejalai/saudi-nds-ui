# @aboalrejal/nds-icons

Saudi Arabia National Design System (NDS) React Icon Library. This package contains over 8,000+ DGA compliant React icon components built for fast compilation and modern web development.

## Installation

```bash
npm install @aboalrejal/nds-icons
```

## Usage

```tsx
import { Icon1StBracketCircleSolid } from '@aboalrejal/nds-icons';

export default function Example() {
  return (
    <div>
      <Icon1StBracketCircleSolid className="w-6 h-6 text-emerald-600" />
    </div>
  );
}
```
