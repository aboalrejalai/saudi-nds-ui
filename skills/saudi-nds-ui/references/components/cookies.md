## Component: COOKIES

DGA-approved **Cookies** component — built on Radix UI / shadcn primitives, styled with NDS design tokens, and optimized for RTL layouts.

### Install

```bash
npx shadcn@latest add https://nds.aboalrejal.com/r/cookies.json
```

**NPM dependencies:** `class-variance-authority`, `@aboalrejal/nds-icons`
**Registry dependencies:** `button` (`https://nds.aboalrejal.com/r/button.json`)

### Usage

```tsx
import { Cookies } from "@/components/ui/cookies";

<Cookies>Cookies</Cookies>
```

> Source not bundled in local registry artifact (`registry/dga/ui/cookies.tsx`). Fetch it via the install command above.
