## Component: DATA-TABLE

DGA-approved **Data Table** component — built on Radix UI / shadcn primitives, styled with NDS design tokens, and optimized for RTL layouts.

### Install

```bash
npx shadcn@latest add https://nds.aboalrejal.com/r/data-table.json
```

**NPM dependencies:** `@tanstack/react-table`, `@aboalrejal/nds-icons`
**Registry dependencies:** `table` (`https://nds.aboalrejal.com/r/table.json`), `button` (`https://nds.aboalrejal.com/r/button.json`)

### Usage

```tsx
import { DataTable } from "@/components/ui/data-table";

<DataTable>Data Table</DataTable>
```

> Source not bundled in local registry artifact (`registry/dga/ui/data-table.tsx`). Fetch it via the install command above.
