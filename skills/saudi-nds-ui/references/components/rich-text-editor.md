## Component: RICH-TEXT-EDITOR

DGA-approved **Rich Text Editor** component — built on Radix UI / shadcn primitives, styled with NDS design tokens, and optimized for RTL layouts.

### Install

```bash
npx shadcn@latest add https://nds.aboalrejal.com/r/rich-text-editor.json
```

**NPM dependencies:** `@tiptap/react`, `@tiptap/starter-kit`, `@tiptap/extension-placeholder`, `@aboalrejal/nds-icons`
**Registry dependencies:** `button` (`https://nds.aboalrejal.com/r/button.json`)

### Usage

```tsx
import { RichTextEditor } from "@/components/ui/rich-text-editor";

<RichTextEditor>Rich Text Editor</RichTextEditor>
```

> Source not bundled in local registry artifact (`registry/dga/ui/rich-text-editor.tsx`). Fetch it via the install command above.
