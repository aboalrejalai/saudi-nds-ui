## Component: DESCRIPTION-LIST

DGA-approved **Description List** component — built on Radix UI / shadcn primitives, styled with NDS design tokens, and optimized for RTL layouts.

### Install

```bash
npx shadcn@latest add https://nds.aboalrejal.com/r/description-list.json
```

**NPM dependencies:** `class-variance-authority`

### Usage

```tsx
import { DescriptionList } from "@/components/ui/description-list";

<DescriptionList>Description List</DescriptionList>
```

> Source not bundled in local registry artifact (`registry/dga/ui/description-list.tsx`). Fetch it via the install command above.
