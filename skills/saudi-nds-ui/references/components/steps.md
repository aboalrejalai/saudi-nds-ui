## Component: STEPS

DGA-approved **Steps** component — built on Radix UI / shadcn primitives, styled with NDS design tokens, and optimized for RTL layouts.

### Install

```bash
npx shadcn@latest add https://nds.aboalrejal.com/r/steps.json
```

**NPM dependencies:** `class-variance-authority`, `@aboalrejal/nds-icons`

### Usage

```tsx
import { Steps } from "@/components/ui/steps";

<Steps>Steps</Steps>;
```

> Source not bundled in local registry artifact (`registry/dga/ui/steps.tsx`). Fetch it via the install command above.
