## Component: FILE-UPLOAD

DGA-approved **File Upload** component — built on Radix UI / shadcn primitives, styled with NDS design tokens, and optimized for RTL layouts.

### Install

```bash
npx shadcn@latest add https://nds.aboalrejal.com/r/file-upload.json
```

**NPM dependencies:** `@aboalrejal/nds-icons`
**Registry dependencies:** `button` (`https://nds.aboalrejal.com/r/button.json`), `progress` (`https://nds.aboalrejal.com/r/progress.json`)

### Usage

```tsx
import { FileUpload } from "@/components/ui/file-upload";

<FileUpload>File Upload</FileUpload>;
```

> Source not bundled in local registry artifact (`registry/dga/ui/file-upload.tsx`). Fetch it via the install command above.
