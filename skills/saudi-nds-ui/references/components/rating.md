## Component: RATING

DGA-approved **Rating** component — built on Radix UI / shadcn primitives, styled with NDS design tokens, and optimized for RTL layouts.

### Install

```bash
npx shadcn@latest add https://nds.aboalrejal.com/r/rating.json
```

**NPM dependencies:** `class-variance-authority`, `@aboalrejal/nds-icons`

### Usage

```tsx
import { Rating } from "@/components/ui/rating";

<Rating>Rating</Rating>;
```

> Source not bundled in local registry artifact (`registry/dga/ui/rating.tsx`). Fetch it via the install command above.
