## Component: FILTER

DGA-approved **Filter** component — built on Radix UI / shadcn primitives, styled with NDS design tokens, and optimized for RTL layouts.

### Install

```bash
npx shadcn@latest add https://nds.aboalrejal.com/r/filter.json
```

**NPM dependencies:** `@aboalrejal/nds-icons`

### Usage

```tsx
import { Filter } from "@/components/ui/filter";

<Filter>Filter</Filter>;
```

> Source not bundled in local registry artifact (`registry/dga/ui/filter.tsx`). Fetch it via the install command above.
