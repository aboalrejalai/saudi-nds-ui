## Component: COMBOBOX

DGA-approved **Combobox** component — built on Radix UI / shadcn primitives, styled with NDS design tokens, and optimized for RTL layouts.

### Install

```bash
npx shadcn@latest add https://nds.aboalrejal.com/r/combobox.json
```

**NPM dependencies:** `@base-ui/react`, `@hugeicons/core-free-icons`, `@hugeicons/react`
**Registry dependencies:** `button` (`https://nds.aboalrejal.com/r/button.json`), `input-group` (`https://nds.aboalrejal.com/r/input-group.json`)

### Usage

```tsx
import { Combobox } from "@/components/ui/combobox";

<Combobox>Combobox</Combobox>;
```

> Source not bundled in local registry artifact (`registry/dga/ui/combobox.tsx`). Fetch it via the install command above.
