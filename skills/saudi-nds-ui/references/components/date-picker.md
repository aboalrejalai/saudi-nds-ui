## Component: DATE-PICKER

DGA-approved **Date Picker** component — built on Radix UI / shadcn primitives, styled with NDS design tokens, and optimized for RTL layouts.

### Install

```bash
npx shadcn@latest add https://nds.aboalrejal.com/r/date-picker.json
```

**NPM dependencies:** `date-fns`, `@aboalrejal/nds-icons`, `react-day-picker`
**Registry dependencies:** `button` (`https://nds.aboalrejal.com/r/button.json`), `calendar` (`https://nds.aboalrejal.com/r/calendar.json`), `popover` (`https://nds.aboalrejal.com/r/popover.json`), `label` (`https://nds.aboalrejal.com/r/label.json`)

### Usage

```tsx
import { DatePicker } from "@/components/ui/date-picker";

<DatePicker>Date Picker</DatePicker>
```

> Source not bundled in local registry artifact (`registry/dga/ui/date-picker.tsx`). Fetch it via the install command above.
