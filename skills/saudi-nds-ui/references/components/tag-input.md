## Component: TAG-INPUT

DGA-approved **Tag Input** component — built on Radix UI / shadcn primitives, styled with NDS design tokens, and optimized for RTL layouts.

### Install

```bash
npx shadcn@latest add https://nds.aboalrejal.com/r/tag-input.json
```

**NPM dependencies:** `class-variance-authority`, `@aboalrejal/nds-icons`
**Registry dependencies:** `badge` (`https://nds.aboalrejal.com/r/badge.json`)

### Usage

```tsx
import { TagInput } from "@/components/ui/tag-input";

<TagInput>Tag Input</TagInput>;
```

> Source not bundled in local registry artifact (`registry/dga/ui/tag-input.tsx`). Fetch it via the install command above.
