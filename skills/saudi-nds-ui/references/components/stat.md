## Component: STAT

DGA-approved **Stat** component — built on Radix UI / shadcn primitives, styled with NDS design tokens, and optimized for RTL layouts.

### Install

```bash
npx shadcn@latest add https://nds.aboalrejal.com/r/stat.json
```

**NPM dependencies:** `class-variance-authority`, `@aboalrejal/nds-icons`

### Usage

```tsx
import { Stat } from "@/components/ui/stat";

<Stat>Stat</Stat>
```

> Source not bundled in local registry artifact (`registry/dga/ui/stat.tsx`). Fetch it via the install command above.
