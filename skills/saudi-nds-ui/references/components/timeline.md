## Component: TIMELINE

DGA-approved **Timeline** component — built on Radix UI / shadcn primitives, styled with NDS design tokens, and optimized for RTL layouts.

### Install

```bash
npx shadcn@latest add https://nds.aboalrejal.com/r/timeline.json
```

**NPM dependencies:** `class-variance-authority`

### Usage

```tsx
import { Timeline } from "@/components/ui/timeline";

<Timeline>Timeline</Timeline>
```

> Source not bundled in local registry artifact (`registry/dga/ui/timeline.tsx`). Fetch it via the install command above.
