## Component: CODE

DGA-approved **Code** component — built on Radix UI / shadcn primitives, styled with NDS design tokens, and optimized for RTL layouts.

### Install

```bash
npx shadcn@latest add https://nds.aboalrejal.com/r/code.json
```

**NPM dependencies:** `class-variance-authority`, `@aboalrejal/nds-icons`

### Usage

```tsx
import { Code } from "@/components/ui/code";

<Code>Code</Code>;
```

> Source not bundled in local registry artifact (`registry/dga/ui/code.tsx`). Fetch it via the install command above.
