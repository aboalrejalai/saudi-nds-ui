## Dynamic Props Usage

All chart components accept dynamic `data` and `config` props while maintaining default fallbacks:

```tsx
import { ChartRadialSimple } from "@/registry/dga/charts/chart-radial-simple"

const customData = [
  { month: "Jan", value: 400 },
  { month: "Feb", value: 700 },
  { month: "Mar", value: 1200 },
]

const customConfig = {
  value: {
    label: "Metrics",
    color: "var(--chart-1)",
  },
}

export default function RadialChartOverview() {
  return (
    <ChartRadialSimple
      data={customData}
      config={customConfig}
      title="Annual Analytics Report"
      description="Regional Statistics 2024"
      trendingText="Trending up by 12.5% this period"
    />
  )
}
```
