## الاستخدام الديناميكي (Dynamic Props Usage)

جميع شارتات المكتبة تقبل ممرّات بيانات ديناميكية (`data` و `config`) مع الاحتفاظ بالقيم الافتراضية التلقائية في حال عدم التمرير:

```tsx
import { ChartBarDefault } from "@/registry/dga/charts/chart-bar-default"

const customData = [
  { month: "يناير", sales: 400 },
  { month: "فبراير", sales: 700 },
  { month: "مارس", sales: 1200 },
]

const customConfig = {
  sales: {
    label: "المبيعات الإقليمية",
    color: "var(--chart-1)",
  },
}

export default function SalesOverview() {
  return (
    <ChartBarDefault
      data={customData}
      config={customConfig}
      title="تقرير المبيعات السنوي"
      description="إحصائيات مبيعات المنطقة الوسطى 2024"
      trendingText="ارتفاع المبيعات بنسبة 18.4%"
    />
  )
}
```
